--------------------------------------------------------------------------------
  1. PROJECT OVERVIEW
--------------------------------------------------------------------------------

This is the backend REST API server for Neyamul's personal portfolio website.
It is built with Express.js and TypeScript, connects to a MongoDB Atlas cluster
for project data, and uses the Resend email service to handle contact form
submissions.

The server exposes three main areas of functionality:
  - Health check route (GET /)
  - Project data routes (GET /projects, GET /projects/:id)
  - Contact form route (POST /api/contact)

--------------------------------------------------------------------------------
  3. ENTRY POINT — src/script.ts
--------------------------------------------------------------------------------

This is the main server file. It performs the following tasks in order:

  a) Loads environment variables from .env via "import 'dotenv/config'"
  b) Creates an Express application instance
  c) Reads PORT and MONGO_URI from process.env
  d) Registers middleware:
       - cors()            → enables Cross-Origin Resource Sharing (all origins)
       - express.json()    → parses incoming JSON request bodies
  e) Mounts the contact router at /api/contact
  f) Defines a health-check route at GET /
  g) Creates a MongoClient with Server API v1 settings
  h) Runs the async "run()" function to:
       - Access the "NeyamulFolio" database
       - Get the "projects" collection
       - Register the /projects and /projects/:id route handlers
  i) Starts listening on the configured PORT


--------------------------------------------------------------------------------
  4. MIDDLEWARE
--------------------------------------------------------------------------------

  cors()
  ------
  Allows all cross-origin HTTP requests. Required so that the frontend
  (hosted on a different domain) can communicate with this API server.

  express.json()
  --------------
  Parses the body of incoming requests with Content-Type: application/json.
  Makes req.body available to route handlers.


--------------------------------------------------------------------------------
  5. API ROUTES
--------------------------------------------------------------------------------

  [GET]  /
  ---------
  Health check route.
  Response: Plain text → "Server is running"
  Purpose : Confirms the server is live.

  ─────────────────────────────────────────────────────

  [GET]  /projects
  -----------------
  Fetches all projects from the MongoDB "projects" collection.
  Response: 200 OK — JSON array of all project documents.

  Example response:
  [
    {
      "_id": "64ab...",
      "title": "My Project",
      "description": "...",
      ...
    },
    ...
  ]

  ─────────────────────────────────────────────────────

  [GET]  /projects/:id
  ----------------------
  Fetches a single project by its MongoDB ObjectId.

  URL param:
    :id  — the MongoDB document _id (24-character hex string)

  Validation:
    - Checks if :id is a valid ObjectId before querying.
    - Returns 400 if the id format is invalid.
    - Returns 404 if no document matches the given id.
    - Returns 500 on unexpected server/database errors.

  Responses:
    200 OK          — JSON object of the found project
    400 Bad Request — { "message": "Invalid project id" }
    404 Not Found   — { "message": "Project not found" }
    500 Server Err  — { "message": "Failed to fetch project" }

  ─────────────────────────────────────────────────────

  [POST]  /api/contact
  ----------------------
  Handles contact form submissions from the portfolio frontend.
  Delegates to src/routes/contact.ts.

  Request body (JSON):
    {
      "name":    "string",   ← required
      "email":   "string",   ← required
      "message": "string"    ← required
    }

  Behavior:
    1. Validates that name, email, and message are all present.
    2. Sends an email via the Resend SDK to neyamulislam946@gmail.com.
       - From    : Portfolio <onboarding@resend.dev>
       - ReplyTo : the sender's email address
       - Subject : "Portfolio Contact from <name>"
       - Body    : Plain text with name, email, and message fields.
    3. Returns success or the appropriate error response.

  Responses:
    200 OK          — { "success": true, "message": "Email sent successfully." }
    400 Bad Request — { "error": "All fields are required." }
    500 Server Err  — { "error": "Failed to send email." }
                      { "error": "Something went wrong." }


--------------------------------------------------------------------------------
  6. DATABASE — MongoDB Atlas
--------------------------------------------------------------------------------

  Provider   : MongoDB Atlas (cloud-hosted)
  Database   : NeyamulFolio
  Collection : projects

  Connection:
    - Uses MongoClient from the official "mongodb" npm driver.
    - Connection string is stored in the MONGO_URI environment variable.
    - Server API version is locked to v1 with strict mode and
      deprecation error reporting enabled.
    - The client.connect() call is currently commented out (MongoDB driver
      v4.7+ auto-connects on first operation).

  Document shape (inferred):
    {
      _id         : ObjectId   ← MongoDB auto-generated unique ID
      title       : string     ← project name
      description : string     ← short description
      ...                      ← any additional fields
    }


--------------------------------------------------------------------------------
  7. EMAIL SERVICE — Resend
--------------------------------------------------------------------------------

  Provider : Resend (https://resend.com)
  SDK      : "resend" npm package

  Configuration:
    - API key is read from the RESEND_API_KEY environment variable.
    - Sender address: onboarding@resend.dev (Resend's shared sandbox domain)
    - Recipient: neyamulislam946@gmail.com (hardcoded)

  Usage:
    - Only triggered by POST /api/contact.
    - The sender's email is set as replyTo so replies go back to the visitor.


--------------------------------------------------------------------------------
  8. ENVIRONMENT VARIABLES (.env)
--------------------------------------------------------------------------------

  PORT             — The port number the server listens on (e.g. 5000)
  MONGO_URI        — Full MongoDB Atlas connection string (includes credentials)
  RESEND_API_KEY   — API key for the Resend email service

  NOTE: The .env file is listed in .gitignore and should never be committed
  to version control. Keep these values secret.
